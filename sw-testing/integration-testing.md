# Integration testing

- Tests a collection of modules integrated into subsystems.
- Helps detect errors at module interfaces.

## Methods

- **Top-down:** Uses stubs so higher-level functionality can be tested early.
- **Bottom-up:** Uses drivers to test lower-level functionality before integrating higher-level modules.
- **Sandwich (hybrid):** Combines top-down and bottom-up integration, working from both ends of the system.

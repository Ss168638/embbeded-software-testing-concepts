# Types of Software Metrics

## Direct Metrics
1. Size (Lines Of Code (LOC) or Function Point (FP))
2. Cost
3. Effort Variance
4. Defect Density
5. Test Pass Rate
6. Time to Fix Defects
7. Requirement Coverage
8. Schedule Variance

## Indirect Metrics
1. Efficiency
2. Productivity
3. Reliability
4. Functionality
5. Complexity
6. Maintainability

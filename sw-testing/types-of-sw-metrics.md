# Types of software metrics

## Direct metrics

Direct metrics measure attributes that can be observed or counted directly.

1. Size, such as lines of code (LOC) or function points (FP)
2. Cost
3. Effort variance
4. Defect density
5. Test pass rate
6. Time to fix defects
7. Requirements coverage
8. Schedule variance

## Indirect metrics

Indirect metrics estimate qualities that are not measured directly.

1. Efficiency
2. Productivity
3. Reliability
4. Functionality
5. Complexity
6. Maintainability

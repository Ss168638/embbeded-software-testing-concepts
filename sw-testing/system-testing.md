# System testing

- Tests the complete system after its subsystems have been integrated.
- Helps identify errors caused by interactions between subsystems.
- Validates the system's functional and non-functional requirements.

## Methods

- Load testing
- Stress testing
- Sanity testing
- Smoke testing
- Chaos testing
- Regression testing
- Volume testing
- Facility testing
- Usability testing
- Security testing
- Storage testing
- Recovery testing
- Procedural testing
